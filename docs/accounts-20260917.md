## 运维与回退

```sh
cd /opt/codex-official-bridge-accounts/account-2
docker compose ps
docker compose up -d --no-build --pull never
```

第三实例将路径改为 account-3。停止单个新增实例用对应目录的 `docker compose stop`。BWH 内部接入通道用 `systemctl status codex-bridge-tunnel` 检查。

认证已由新网关维护，回退前必须暂停 Sub2API 对应渠道、排空请求并停止相应网关，读取网关最新 auth.json，核对并将最新凭据迁回 Sub2API。不能盲目用迁移前备份中的 RT 覆盖最新状态。恢复原 type/proxy_id/credentials 后，需要发出调度器更新事件并核对 Redis 快照；不能只改数据库而保留旧缓存。冷备不是另一套可同时刷新的活动凭据。
